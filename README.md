# LAST SIGNAL: SHIFT

A sci-fi pixel-art survival game built with Godot 4.

## Run the movement prototype

Open this folder in Godot 4.7 and run the project (F6/F5, or the Run Project button).
The main scene is configured as `scenes/main/Main.tscn`.

Move the player with **WASD** or the **arrow keys**. The prototype uses a 320x180
base viewport and a temporary player sprite and room.
